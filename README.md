### Project description
  Our project will focus on training a neural network to classify chest X-ray images as either normal or showing signs of pneumonia. Pneumonia is a lung infection that can be detected from images, and image classification using convolutional neural netowrks has been used for this type of medical diagnosis. The goal is to apply deep learning techniques to train and evaluate different neural network architectures on a real medical imaging dataset.
  We plan to use the Chest X-ray pneumonia dataset available on Kaggle, which contains labeled X-ray images of patients with and without pneumonia. The dataset includes separate training and testing images that can be used to evaluated model performance. The images will be resized and processed before being used as input into the neural network. The main model used in this project will be a CNN, since CNNs are suited for image classification. We will experiment with different network architectures and parameters, such as the number of convolutional layers, numbers of neurons, learning rate, batch size, and activation functions. We will compare at least two different architectures and test several parameter choices to determine which model produces the best classification accuracy.
  The performance of the models will be evaluated using training and test accuracy, loss curves, and matrices. We will compare difference architectures and discuss how the rdesign of the neural network affects performance on medical image classificaiton.
